# 应用启动与状态标记

Native 文件夹在布局提交后同步内容与页码；关闭动画保留其展示快照。删除入口共享这一同步点。

Windows 普通文件扫描使用 Shell 显示名；来源分组使用本地化名称显示、真实相对路径标识。用户自定义名称仍优先。扫描不会改写磁盘名称。

右键支持定位程序文件、定位来源快捷方式、单次管理员启动；编辑中的“始终以管理员身份运行”保存于手动应用或目录应用引用的 `runAsAdmin`。快捷方式提权保留解析出的参数、工作目录与显示方式，不修改源文件。

管理员盾牌依据用户配置、快捷方式 RUNAS 标记、程序 manifest 和 AppCompatFlags/Layers 的 RUNASADMIN 设置显示。运行后才请求提权的程序不能预先可靠识别；highestAvailable 不被当作必需管理员权限。用户自定义图片内已绘制的盾牌无法可靠自动剥离。

应用设置下拉选项为不显示／问号／禁止符号，默认问号；禁止符号带白色半透明圆形底片。失效检查独立于标记显示；保留未知状态，支持文件恢复及等价备用来源。菜单保留编辑、重新检查、移除与有效的定位操作。仅图片加载失败不标记启动目标失效。

文件定位成功后启动台收起，下一次显示保留文件夹和搜索；失败时保持可见。单次管理员启动经过统一启动动画，提权参数只属于该启动会话，取消后恢复窗口。

“先播完动画，再弹出 UAC”默认关闭，独立于同样默认关闭的盾牌显示。已有明确保存的设置值保留。开启后，单次提权、用户持久配置或已有检测结果表明需要管理员权限时，等待动画完成及窗口隐藏后再请求启动；关闭开关恢复并行启动。普通应用不增加等待，动画期间重新打开启动台会取消尚未发出的请求。

普通点击不等待全量状态检查；已知失效项只重检自身。后台检查按小批次提交，单项结果合并到状态表。真正启动仅检查选中目标及必要备用来源，不重复查询管理员清单。Alt 编辑按钮使用居中矢量线条，避免字体基线与字号差异。

EXE 权限查询显式选择内嵌 manifest 资源 1。FanControl 实测需要管理员权限；读取失败保留未知信息，不能当作“不需要”。

布局载入失败时显示独立不透明恢复面板，支持重试、配置定位、错误详情复制及确认后的备份重置。备份同步落盘成功后才移除原布局，失败不重置；扫描阶段失败不提供重置布局操作。

恢复面板默认显示只读多行错误详情，可选择、复制和滚动；常见错误中的文件路径单独列出。定位与复制为辅助操作，底部左侧重置、右侧退出和重试，默认焦点为重试。重置确认默认聚焦取消。

## 验证入口

项目检查：`npm run check`。平台测试：`cargo test -p lumeria-core -p lumeria-native-data --locked`。实际 sidecar 集成：`npm run test:native-data`。

隔离 Native 功能截图和断言：设置 `LAUNCHPAD_TARGET_ACTIONS_PROOF` 为绝对输出目录，运行 `npx tsx scripts/runNativeElectrobun.ts --dev --isolated`。检查该目录 `proof.json` 的 passed 结果；开发运行器退出码本身不足以证明用例通过。

此功能更新当前未发布的数据契约，不包含旧格式迁移。资源管理器定位已通过真实 Shell 选中项验证；UAC 安全桌面确认/取消仍需交互验收。
