# 末页托盘三角形与动画问题

2026-09-17。用户截图：最后一页，Esc或空白关闭后从托盘打开，出现以页码附近为顶点的巨大灰色三角面；在该进程中重复出现，切页消失，重启后未能再次复现。并报告快速Alt+Space关闭时灰底偶尔残留、w/Backspace搜索往返入场不一致。

## 末页异常（未确认根因）

- 隔离12页、每页28项、末页9项、1920×1080。24次交替Esc/空白关闭，均通过真实Shell托盘通知唤出。中途选择/设置切换及一次70秒隐藏停留；未强制GC或设备恢复。
- 每次恢复动画结束后用OS屏幕抓取，不通过renderer.extract改变绘制路径。比较中下部原本无内容区域，24次不同像素数均0；未复现巨大三角形。
- 本轮用纯色底和合成普通应用图标，未覆盖用户原背景材质、全部真实文件夹/图标分布、运行历史、DPI/驱动压力。此结果不证明问题已解决。
- 透明窗口明确绕过native fast render bundle；不能把问题归因于该分支。截图形状更像几何/批次数据异常，但仅为待证假设。未为此加入每次重建/禁用缓存等绕过措施。
- 原始观测与截图：artifacts/last-page-tray-probe/results.json及baseline/tray-00..23.png。复发时应在切页/重启前获取相同帧的CPU几何/批次、GPU状态与日志，才可定位。

## 快速开关背景

确定性内存重放：打开淡入进行50ms后按关闭路径直接赋alpha=0；再推进16ms，旧动画将alpha写回0.6189。源在beginNativeWindowClose直接赋值未取消打开动画。

修复：背景立即隐藏时先kill alpha动画，再赋0；普通chrome淡出保持原流程。单测覆盖16/50/120/220ms打断，关闭后的20帧始终0，后续打开恢复1。原生回归新增16/40/80/140/220ms开关打断，逐呈现帧检查alpha。

## 搜索入场

确定性重放：desktop→w时已有Word alpha=1；w→desktop时Word alpha=1、非匹配Other alpha=0，同页出现混合入场。knownDesktopItems是前一scope的ID集合，被错误用于跨desktop/search scope的入场决策。

修复：只在同scope的页挂载复用时跳过入场；跨scope的出现节点统一走入场，无论新建还是缓存复用。不会让普通翻页重新淡入；不改搜索结果排序或纹理缓存。
