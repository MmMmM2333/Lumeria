# 文字预热与窗口恢复计时

2026-09-17，用户授权范围：文字分批预热、恢复过程分段计时。未调整图标尺寸、显存预算、窗口恢复策略。

## 实现

- 首屏呈现后启动，最多8个标签或2ms一批，批间让出事件循环。单次文字栅格化不可中断，因此2ms是开始下一项的截止预算，不是硬实时上限。
- 沿途页面优先；保留页面场景提供候选。隐藏暂停、再次显示恢复，名称/布局变化释放旧缓存引用。
- 借用Pixi的引用计数文字纹理缓存；实际绘制取得引用后，释放预热引用。没有将离屏节点设为可见，没有改图标缓存。
- 恢复计时只在诊断构建记录：窗口显示、激活、材质操作、场景提交和render/present时间点；设备恢复后重新绑定监听，销毁时清理。

## 隐藏60秒后恢复的分段结果

两次恢复到首帧约126ms、153ms，无文字纹理重建。

各同步阶段与时间点之间有等待和其他工作，表中不是完整互斥耗时分解。最大已观测同步开销是场景提交；下一步应定位恢复时为什么进入完整场景提交。当前没有将其归因于GC，也没有改变恢复行为。
