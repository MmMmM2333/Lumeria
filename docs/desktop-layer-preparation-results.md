# 桌面层准备与文件夹按需展开

2026-09-17，用户授权实施准备清单、缩略图交互补齐、桌面保留与展开解耦。启动等待策略未前移。

## 行为

- 所有布局图标继续保留数据所有权，后台准备队列只包含桌面普通应用和每个文件夹首页前min(9,folderPageSize)个缩略图，按图片来源去重。
- 静态文件夹预览最多9项。进入原有拖拽悬停/滚动预览状态时按需扩展至原预览范围，退出动画结束后恢复九宫格；不是运行期硬限制9项。
- 至少4页、最多800个桌面项、桌面项+初始预览项总数不超过1600时保留桌面节点；文件夹内部页仍首次展开时建立，未打开文件夹内部文字不预热。超过范围仍使用有界挂载。
- 文件夹开合在桌面依赖不变时只重算活动页文件夹外壳和展开层；普通应用及离屏桌面页保持原节点，拖拽/布局变化等复杂状态回到完整路径。既有源图标隐藏和交接流程保留。

## 实机结果

10页×80桌面格：780普通应用+20文件夹，各含20子项；128px独立图片，RTX3060 Laptop GPU，1920×1080。

- 默认5×7子页：首屏/空闲队列清空后驻留960张（780+20×9），约80MiB；打开一个文件夹增加11张到971，其余19个文件夹内容不加载。对照数据artifacts/desktop-folder-layer-35.json与-final.json。
- 最终首次远跳122ms，热往返31–32ms，无桌面结构重建；原按需文件夹路径首次远跳659–664ms。尚有冷文字/绘制开销，没有宣称立即跨页零顿挫。
- 首次展开约291ms，重开约252ms（含动画）；此前简单强制全挂载实验约370–381ms。2×2子页场景首开295ms，与旧2×2按需253–256ms相比仍有差距，但已显著减少强制全挂载的回退。当前关闭至交接完成约0.87–0.92秒，非主线程阻塞时长。
- 节点准备仍在现有启动阶段进行，首次可用场景约5.09秒（含宿主初始化），没有改为“全部文字准备好才显示”。
