# 启动准备策略与验收

2026-09-17。授权：登录后台准备桌面层，主动启动150/250/400ms限时对照，支持用户提前打开；普通后台恢复不重复启动等待。

## 最终策略

- 数据加载期间隐藏窗口；加载失败的重试/取消通知明确显示并激活窗口，防止隐藏等待用户输入。
- 登录自启：首个可用场景后开始隐藏状态的桌面图标/文字分批预热，全部准备或预算队列结束后仍保持隐藏。用户提前唤出直接接管显示，取消启动等待、优先当前页，剩余工作继续分批进行。
- 主动启动：当前页准备好后不增加额外等待。保留one-shot限时控制，但默认预算0；测试未支持启用150–400ms的固定等待。只在启动阶段执行一次，后续hide/show不重做。
- 仅准备现有桌面清单，不包含所有未打开文件夹内部内容，不改变图标320MiB预算，不修改系统自启注册或新增用户选项。
- 原生宿主创建HWND后才返回，目前应用只能在返回后立即hide；这不是声称OS层从未出现过窗口。彻底无闪现需要宿主支持初始隐藏窗口选项，本轮未更改vendor宿主。
